# 🐍 Snake Game using Python & Tkinter

## A simple Snake Game built with Python and the Tkinter graphics library. Learn how to build classic games while practicing logic, GUI development, and event-driven programming!

## 🚀 Features
- GUI created using Tkinter  
- Game loop and frame updates  
- Arrow key controls  
- Collision detection and Game Over screen  
- Scoring system  
- Restart game with SPACE key  
- (Optional) High Score tracking
